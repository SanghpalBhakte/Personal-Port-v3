# Contributing Guidelines

Thank you for your interest in contributing to **Sanghpal Bhakte's Portfolio**!

## Development Workflow

1. **Clone the repository**:
   ```bash
   git clone https://github.com/<YourUsername>/sanghpal-portfolio.git
   cd sanghpal-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development**:
   ```bash
   npm run dev
   ```

4. **Verify code quality**:
   ```bash
   npm run lint
   npm run build
   ```

## Commit Conventions

We follow the [Conventional Commits](https://www.conventionalcommits.org/) specification:
- `feat:` A new feature or section
- `fix:` A bug fix or UI patch
- `docs:` Documentation updates
- `style:` Code style, formatting, or CSS polish
- `refactor:` Code refactoring without functionality changes
- `chore:` Dependency or build tool updates
